# milan0x/tap

Homebrew tap for [MicGuard](https://github.com/milan0x/MicGuard).

```bash
brew tap milan0x/tap
brew install --cask micguard
# or
brew install --cask local-cloud-browser
```

The cask installs the same Apple-notarized DMG published on the MicGuard
[Releases](https://github.com/milan0x/MicGuard/releases) page. A scheduled
workflow keeps the cask pointed at the latest release.
